generate_era5_patches(era5: Dataset, tiles: list) → tuple[ndarray, list]

Generate ERA5 inputs for the model based on the tiles metadata.

Skip tiles that contain only sea values.

Parameters:

  • era5 (xr.Dataset) – The ERA5 dataset.

  • tiles (list) – A list of dictionaries containing metadata for each tile.

Returns:

A tuple containing the ERA5 patches (numpy arrays) and their corresponding metadata (list of dicts).

Return type:

tuple[np.ndarray, list]

Run the preprocessing pipeline for the RCM emulator.

  • rcm_zarr_path (str) – Path to the RCM data.

Returns:

A tuple containing:

The ERA5 dataset reprojected to the RCM grid.

tuple[np.ndarray, list, list, xr.Dataset, xr.Dataset]

run_preprocessing_loc(gcm_zarr_path: str, rcm_zarr_path: str, location: tuple[float, float]) → tuple[ndarray, list, dict, Dataset, Dataset]

Run the preprocessing pipeline for the RCM emulator.

Parameters:

  • gcm_zarr_path (str) – Path to the GCM data.

  • rcm_zarr_path (str) – Path to the RCM data.

  • location (tuple[float, float]) – The latitude and longitude of the location for which to run the preprocessing.

Returns:

A tuple containing:
input_patches: np.ndarray

A numpy array containing the preprocessed ERA5 patches ready for model input.

patch_metadata: list

A list (one entry per month) of single-item lists of dictionaries containing per-patch metadata (e.g. “time_idx”), as expected by the prediction pipeline.

tile_meta: dict

Metadata about the single tile location (slices, center coords, etc.), as expected by the location-based postprocessing step.

rcm_ds: xarray.Dataset

The RCM dataset.

era5_xy: xarray.Dataset

The ERA5 dataset reprojected to the RCM grid.

Return type:

tuple[np.ndarray, list, dict, xr.Dataset, xr.Dataset]
