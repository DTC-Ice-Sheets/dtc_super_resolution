predict(model: Module, input_patches: ndarray, metadata: list, device: device) → ndarray

Run inference on the model using the provided DataLoader.

Parameters:

  • model (nn.Module) – The trained PyTorch model.

  • input_patches (np.ndarray) – A list of numpy arrays containing preprocessed input patches for inference.

  • metadata (list) – A list of dictionaries containing metadata for each input patch.

  • device (torch.device) – The device to run the inference on (CPU or GPU).

Returns:

Model predictions with shape (time, tiles, height, width).

Return type:

np.ndarray

Post-process the model’s predictions to match the original input shape.

Parameters:

  • monthly_predictions (np.ndarray) – The model’s predictions.

  • metadata (list) – A list of dictionaries containing metadata for each input patch.

  • tiles (list) – A list of dictionaries containing metadata for each tile.

  • rcm_ds (xr.Dataset) – The RCM dataset.

  • era5_xy (xr.Dataset) – The ERA5 dataset reprojected to the RCM grid.

Returns:

The post-processed predictions.

Return type:

np.ndarray
