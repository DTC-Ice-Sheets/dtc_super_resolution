build_loc_tiles(lon: float, lat: float, era5_ds: Dataset, racmo_ds: Dataset, era5_tile_px: int = 48, racmo_tile_px: int = 224) → tuple[ndarray, ndarray, dict]

Build one ERA5 input tile and one RACMO target tile centered on a user-selected lon/lat (EPSG:4326) location.

Parameters:

  • lon (float) – Longitude of the location selected on the map, in EPSG:4326.

  • lat (float) – Latitude of the location selected on the map, in EPSG:4326.

  • era5_ds (xr.Dataset) – ERA5 dataset already reprojected onto the EPSG:3031 grid (dims: time, variable-per-DataArray, y, x).

  • racmo_ds (xr.Dataset) – RACMO dataset on its native EPSG:3031 grid (must contain ‘surface_mass_balance_glaciated’ or similar).

  • era5_tile_px (int) – Height/width (in ERA5 pixels) of the input tile. Default 48.

  • racmo_tile_px (int) – Height/width (in RACMO pixels) of the target tile. Default 224.

Returns:

  • input_tile (np.ndarray) – Shape [T, 1, len(era5_vars), era5_tile_px, era5_tile_px]

  • target_tile (np.ndarray) – Shape [T, 1, racmo_tile_px, racmo_tile_px]

  • tile_meta (dict) – Info about the tile location (slices, center coords, etc.)

clip_data_to_intersection(racmo: DataArray, era5: DataArray) → tuple[DataArray, DataArray]

Clip RACMO and ERA5 datasets to their intersection.

Because both grids are co-registered (same origin, ERA5 = scale x RACMO), the intersection is simply the overlapping region of the two arrays.

Parameters:

  • era5 (xr.DataArray) – ERA5 data array (2D) in EPSG:3031 projection.

Returns:

A tuple containing the clipped RACMO and ERA5 data arrays.

tuple[xr.DataArray, xr.DataArray]

generate_tile_indices(racmo: DataArray, era5: DataArray, tile_racmo_h: int, tile_racmo_w: int, scale_x: int, scale_y: int, stride_frac: float = 1.0, context_pad: tuple[int, int] = (0, 0)) → list[dict]

Generate paired RACMO / ERA5 index slices for all tiles.

Because both grids are co-registered (same origin, ERA5 = scale x RACMO), ERA5 pixel k maps to RACMO pixels [k*scale, (k+1)*scale). The stride is snapped to a multiple of the scale factors so tiles always align exactly.

Parameters:

  • racmo (xr.DataArray) – RACMO data array (2D) in EPSG:3031 projection.

  • era5 (xr.DataArray) – ERA5 data array (2D) in EPSG:3031 projection.

  • tile_racmo_h (int) – Height of the RACMO tile in pixels.

  • tile_racmo_w (int) – Width of the RACMO tile in pixels.

  • scale_x (int) – Scale factor in the x-direction (ERA5 pixels per RACMO pixel).

  • scale_y (int) – Scale factor in the y-direction (ERA5 pixels per RACMO pixel).

  • stride_frac (float) – Fraction of tile size used as stride. 1.0 → non-overlapping, 0.5 → 50 % overlap, etc.

  • context_pad (tuple[int, int]) – Extra ERA5 pixels added on each side of the ERA5 patch (height, width), providing spatial context beyond the RACMO target region. E.g. context_pad=(2, 2) gives an ERA5 patch of (tile_era5_h + 4) x (tile_era5_w + 4). Tiles where the padded ERA5 patch would exceed the array bounds are dropped.

Returns:

racmo_slice_y/x - isel slices into racmo_clip era5_slice_y/x - isel slices into era5_clip (padded)

Return type:

list[dict]

save_tiles_to_disk(era5: DataArray, racmo_files: list[str], tiles: list[dict], output_dir: str, max_nan_frac: float = 0.95) → None

Save RACMO and ERA5 tile patches to disk as compressed .npz files.

For each RACMO file, we iterate over the tiles and save the corresponding RACMO and ERA5 patches to disk.

Tiles are stored as .npz files: tile_<row>_<col>_<year>.npz with keys era5 and racmo. We filter out ocean-only tiles before saving using the RACMO land mask (NaN fraction check).

Parameters:

  • era5 (xr.DataArray) – ERA5 data array (2D) in EPSG:3031 projection.

  • racmo_files (list[str]) – List of paths to RACMO .zarr files.

  • tiles (list[dict]) – Each dict contains slices for RACMO and ERA5 tiles.

  • output_dir (str) – Path to the output directory.

  • max_nan_frac (float) – Maximum fraction of NaN to_numpy() allowed in a tile.
