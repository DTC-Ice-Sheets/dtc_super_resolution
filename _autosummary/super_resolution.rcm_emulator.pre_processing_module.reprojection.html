create_target_grid_from_racmo(racmo_ds: Dataset, resx_km: float = 14.0, resy_km: float = 28.0) → tuple

Create a uniform grid in EPSG:3031 spanning the RACMO domain at a given resolution.

In our case, we select a resolution that approximately matches the ERA5 grid spacing at our target latitude of 75°S, which is around 14km in x, and around 28km in y.

Parameters:

  • racmo_ds (xr.Dataset) – The RACMO dataset containing the original grid information.

  • resx_km (float) – The desired resolution in the x-direction (in kilometers).

  • resy_km (float) – The desired resolution in the y-direction (in kilometers).

Returns:

A tuple containing the x and y coordinates of the target grid.

Return type:

tuple

reproject_era5_to_racmo_grid(era5_ds: Dataset, gridx: ndarray, gridy: ndarray) → Dataset

Reproject ERA5 (EPSG:4326, lat/lon 0-360) onto a polar stereographic EPSG:3031 grid.

Uses the same inverse-transform approach as InterpolateGCM: each target (x,y) point is converted back to lat/lon, then used as a lookup coordinate in ERA5.

Parameters:

  • era5_ds (xr.Dataset) – The ERA5 dataset containing the original lat/lon grid.

  • gridx (np.ndarray) – The x coordinates of the target grid in EPSG:3031.

  • gridy (np.ndarray) – The y coordinates of the target grid in EPSG:3031.

Returns:

The ERA5 dataset reprojected onto the target polar stereographic grid.

Return type:

xr.Dataset
