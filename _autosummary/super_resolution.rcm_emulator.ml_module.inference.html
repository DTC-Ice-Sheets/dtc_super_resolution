run_inference(model_name: str, input_patches: list, metadata: list) → dict

Run inference on the RCM emulator model.

Parameters:

  • model_name (str) – The name of model to use for inference.

  • input_patches (list) – A list of numpy arrays containing preprocessed input patches for inference.

  • metadata (list) – A list of dictionaries containing metadata for each input patch.

Returns:

A dictionary containing the model’s predictions.

Return type:

dict

Raises:

ValueError – If the specified model name is not found in the configuration file.
